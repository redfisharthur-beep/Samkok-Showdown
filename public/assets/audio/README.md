# 音樂與音效

由使用者提供音檔並上傳至本資料夾，沿用下列檔名：

| 檔名 | 用途 |
|---|---|
| bgm-home.mp3 | 首頁、陣營選擇、牌組、國戰、戰績、配對及結算循環音樂 |
| bgm-battle.mp3 | 戰鬥循環音樂 |
| sfx-hit.mp3 | 實際受傷時的打擊音效 |
| sfx-death.mp3 | 部隊或主公陣亡音效 |
| sfx-victory.mp3 | 勝利結算音效 |
| sfx-defeat.mp3 | 失敗結算音效 |

建議打擊音效 0.1～0.4 秒，陣亡 0.3～1 秒，勝敗 1～3 秒。音樂可較長，結尾適合循環。
首次點擊或按鍵後啟動聲音；切到背景暫停，回到遊戲恢復音樂。未提供或載入失敗的音檔保持靜音，不阻擋遊戲。平手沿用首頁音樂。
