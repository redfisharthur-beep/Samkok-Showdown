# 三國爭鋒 Samkok Showdown

可玩的單機 AI 原型：拖曳出牌、主公走位、自動戰鬥、聚氣絕招、陣營與牌組編輯。

## 啟動

Node.js 20+，無第三方執行依賴。

```sh
npm start
# http://localhost:3000
npm test
```

Cloudflare Workers：連接此倉庫，部署命令 `npx wrangler deploy`；靜態資產設定已放在 wrangler.jsonc。Cloudflare Pages 也可直接以 public 作輸出目錄，不需要編譯。此提交不代表已部署，需在你的 Cloudflare 專案連線。

## 第一版規則

- 蜀劉備／魏曹操／吳孫權／群董卓，開局即存在；點主公再點地面移動，也可按「主公走位」。自動索敵與攻擊。
- 32 張卡：每國 4 武將、8 通用兵種、8 通用法術；牌組 8 張，不重複，最多 3 法術；戰鬥 4 張手牌＋循環牌庫。
- 士氣上限 10，初始 5，每秒 0.4，最後 60 秒每秒 0.65。兵種只能部署己方下半場（AI 為上半場），法術可指定全場。
- 聚氣由傷害／受傷每 100 生命 +1、擊殺 +3、建築摧毀 +15，主公死亡期間不增加；主公承受法術傷害減少 25%。每局絕招限一次，死亡 12 秒後復活，敵方士氣 +1。
- 劉備：全體友軍攻擊 +20% 持續 6 秒，現有友軍恢復最大生命 8%。曹操：敵軍防禦 -25% 持續 5 秒，本人命中另降防 10% 持續 2 秒。孫權：友軍移速 +25%、攻速 +15% 持續 6 秒，士氣 +2。董卓：自身攻擊 +35%、防禦係數 +0.30 持續 7 秒，附近敵人恐懼 1.5 秒，結束扣目前生命 15%。
- 防禦使用減傷係數；曹操是降低此係數，不等同增加 25% 最終傷害。後續平衡需要實戰資料。
- 2 本國武將聚氣 +5%，4 本國武將生命 +5%。目前每國僅 4 武將，所以未加入無法達成的 6 張羈絆。
- 3 分鐘：主城被毀立即結算；時間到比較三座建築剩餘生命比例總和，相同則平手。
- 首選陣營免費。本機初始 1 枚轉國令；转國消耗 1 枚、30 天冷卻、演練貢獻清零，歷史戰績與各國牌組保留。尚未實作季度發放或貨幣購買。

## 原始模組

- public/src/data.js：卡池、陣營、素材路徑、牌組驗證
- public/src/engine.js：戰鬥、AI、傷害、法術、復活、結算
- public/src/app.js：頁面、指標、拖曳、主公操作、Canvas、存檔
- public/style.css：唯一樣式來源，不追加覆寫補丁
- tests/engine.test.js：規則及完整對局測試

## 目前範圍

AI 對戰已可玩，資料保存在此瀏覽器 localStorage。此版本不含伺服器登入、真人 PvP、全球國戰、排行榜、商城或資產動畫播放器。AI 演練貢獻不會當作正式國戰資料。清除瀏覽器資料會清除本機進度，轉國限制也不是伺服器權威規則。

戰場為 600×1000 上下兩軍，中央河流 y=460–540，雙橋中心 x=150／450、寬 88；所有移動沿可通行最短路線過橋。遠程可隔河攻擊，近戰仍需走到射程內。尚無單位碰撞或主公手動普攻；武將能力是第一版自動戰鬥邏輯，尚未加入趙雲方向滑動等額外操作。所有數值待平衡。音樂與 idle/walk/attack/skill/death 動畫目錄僅預留，未播放。

更新請遵守 AGENTS.md，直接修改原檔並記錄 CHANGELOG.md。

## 河流雙橋操作

玩家在下方，AI 在上方。兵種部署需在 y≥560（AI y≤440）；法術可指定全場，伏兵與拒馬不能放在水中。主公點到河面時目的地會吸附至最近河岸；跨河命令自動選擇最短橋路。恐懼與擊退也檢查水面，禁止穿越河流。
