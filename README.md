# 三國爭鋒 Samkok Showdown

試煉、LINE 真人自動配對、逐州國戰。圖像由使用者提供，Noto Sans TC 與莫蘭迪配色。

## 啟動與部署

Node.js 20+；遊戲執行無第三方前端依賴。

```sh
npm start
# http://localhost:3000（靜態前端與試煉）
npm test
```

真人登入與國戰需要 Cloudflare Workers / Durable Objects，不能只部署 public 靜態資料夾。設定與驗收見 DEPLOYMENT.md。使用者自行部署 Cloudflare，本次 GitHub 更新不代表正式網址已更新。

## 戰鬥規則

- 四國各 4 名武將、8 通用兵種、8 法術，共 32 張牌。8 張牌組不得重複，最多 3 法術；4 張手牌循環。
- 士氣初始 5、上限 10；每秒 +0.4，最後 60 秒每秒 +0.65。軍隊限己方半場，法術可指定全場；伏兵、拒馬不能放水中。
- 主公在主堡前出生／復活，活動範圍限己方河岸，不上橋、不過河。自動追擊己方區域內最近的敵方角色，射程內的河對岸敵人也可攻擊；不攻擊建築。拖曳主公後放開或點擊戰場可走位，越界目的地限制於己方邊界；手動移動期間停止攻擊、優先脫戰／支援，抵達後恢復自動戰鬥。無可攻擊敵人與手動指令時返回主堡前。其他兵種過河須走雙橋。
- 主公死亡 12 秒後復活，敵方士氣 +1。傷害與受傷每 100 生命聚氣 +1，擊殺 +3，摧毀建築 +15；主公死亡或絕招用過不再聚氣。主公承受法術減傷 25%。
- 每局專屬絕招一次；施放時全螢幕圖像並暫停戰鬥 2 秒。蜀恢復與攻擊增益、魏降防、吳機動與士氣、群強化與恐懼；數值以 public/src/data.js 及 engine.js 為準。
- 2 本國武將聚氣 +5%，4 本國武將使召喚的本國武將生命 +5%。防禦是減傷係數，降低防禦不等同直接增加同幅度最終傷害。
- 軍醫向前行進，追隨目前血量數值最少的受傷友軍，每秒最多治療一次；無傷者時跟隨友軍前線，無部隊時自行前進。突進單位連續移動 60 邏輯單位後，下一擊傷害 ×1.5，使用後 8 秒才能重新準備；不增加基礎移速。
- 遠程攻擊的傷害在投射物抵達後結算；特技暫停也凍結投射物。受擊、攻擊、步行與死亡淡出使用既有靜態圖，不生成替代圖。
- 摧毀主堡立即獲勝；180 秒後比較三座建築剩餘生命比例總和，相同為平手。可確認後投降。

## 試煉與真人

- 試煉依最近 20 場本機勝率調整，40% 以下入門、80% 以上完整戰術；不足 5 場降低調整幅度，每場難度變化最多 0.1。快攻／防守／攻城三種合法牌組輪替。隱藏對手名字。
- 真人須 LINE 登入；自動配對、雙方預載完成才開始。配對可取消，15 秒無排隊心跳過期，30 秒未就緒解除配對。
- 真人所有操作由伺服器驗證，出牌核對卡牌與操作編號，重試不重複扣士氣。每約 200 ms 取得狀態，畫面平滑顯示角色位置。
- 斷線超過 3 秒暫停模擬；30 秒內重連恢復。單方超時判負，雙方皆超時為平手。重新整理或登入新頁籤可恢復對戰。
- 戰績分試煉與對戰，明細按需展開；真人完整操作紀錄分段保存與分頁讀取。試煉資料只在本機，不加入國戰。

## 國戰

- 使用 map.webp 與沿圖定位的 13 州向量輪廓。州的歸屬是伺服器保存的州戰結果，不再依比例每次重新分州。
- 點州選攻／守並自動配對。一般對戰會自動指定交戰州；指定州的配對只接受相容目標、不同國玩家。
- 勝方 +10、敗方或平手 +2 國戰貢獻。攻方勝利把獲得的點數加入該國攻佔進度，達 30 點換主並清空進度；守方勝利削減其他勢力進度，削減量為此次貢獻的一半向上取整。
- 同國、未滿 20 秒、任一方沒有走位／出牌／絕招操作，不增加國戰貢獻，仍保存勝負。相同對手每天依序給 100%、50%、25%、0%，點數向下取整；台灣午夜換日。
- 台灣每週一 00:00 開始新週期，13 州回到未佔領、個人與國家本週貢獻重新計算；上週以佔領面積判定勝出並保留摘要。歷史真人戰績保留，舊版累積貢獻不回填新州戰。
- 面積含未佔領區域，13 州各只有一個歸屬；向量輪廓為遊戲美術定位，非歷史測繪資料，海域不著色。
- 每 30 天補充一枚轉國令，上限一枚；轉國仍需距上次 30 天，清空個人本週貢獻，既有國家戰果保留。對戰未結束不能修改陣營或牌組。

## 遊戲流程與保存

首頁主入口為試煉／對戰／國戰，次要入口為牌組／戰績／裝備，均使用使用者提供圖片；裝備入口開啟四欄位收藏與穿戴。「跳槽」整合於牌組右上角，沿用轉國令及 30 天規則。牌組無儲存按鈕，選牌自動保留本機草稿，選滿合法八張時自動同步 LINE 雲端。未滿八張不可離開牌組開始對戰；儲存失敗保留草稿並提示，返回時重試，不使用舊牌組冒充本次選擇。

選陣營 → 選 8 張牌 → 試煉／真人對戰／點州國戰 → 戰鬥 → 結算 → 再戰或返回。每個陣營可用本國 4 武將、8 通用兵種及 8 法術，共 20 張可選牌。初次選國不花轉國令。

- 初始四張手牌依牌組順序；打出的卡移到牌組尾端，不能重複佔用牌組位置，無效出牌不扣費、不換牌。
- 絕招兩秒全螢幕期間戰鬥時間、角色、投射物、士氣與聚氣皆暫停；不能走位或出牌。真人斷線暫停同樣凍結戰鬥。
- 雙方主堡同時摧毀為平手；時間到比較每座建築「剩餘生命／最大生命」三項總和，非直接比較剩餘生命總數。主公生命與擊殺數不參與勝負比較。
- 真人紀錄保存雙方、陣營、牌組、交戰州、時間、結果、貢獻與操作；每次操作帶唯一識別，重試不重複執行，雙方互相看不到手牌。完整操作紀錄僅參戰者可讀。
- 本機試煉紀錄與 LINE 雲端真人紀錄分開；真人戰績頁最近 30 場，紀錄按需展開，操作分頁每次 100 筆。
- 本機選國不代表全球人數；全球勢力人數與州戰來自 LINE 帳號和伺服器。

## 原始模組與資產

- public/src/data.js：卡池、陣營、試煉牌組、驗證。
- public/src/engine.js：共用戰鬥、尋路、兵種、特技、勝負。
- public/src/app.js / public/style.css：原生介面、拖曳、Canvas、操作回饋。
- public/src/territory.js：州輪廓、點選、面積；src/campaign.js：週期、州戰、貢獻。
- src/worker.js：LINE、帳號、自動配對、伺服器戰鬥與保存。
- tests/：引擎、配對、重連、紀錄及州戰測試。

圖像清單與待補圖見 public/assets/README.md。沒有商城、領土貨幣收益或獨立精靈動畫；目前不引入未定義的經濟系統。伺服器仍以輪詢同步，尚非 WebSocket。

修改請遵守 AGENTS.md，直接修改原始模組並記錄 CHANGELOG.md。

非戰鬥畫面共用使用者提供的 `battlefield/background.webp` 全螢幕背景，置中等比例填滿；戰鬥保持 `battlefield-01.webp`。

手機牌組採緊湊高度，桌面保留原尺寸。法術以動態範圍圈、火球爆炸、落雷、分波箭雨與持續火焰辨識，繪圖不改戰鬥數值。

未登入 LINE 可用訪客模式選陣營、編輯牌組與進行試煉，資料僅存本機；可查看國戰，但真人配對與國戰貢獻需要 LINE 登入。試煉勝敗不改變全球國戰。耗費分為 1 費斥候、2 費遠程／治療／支援、3 費機動武將、4 費重裝／攻城、5～6 費主力；基礎移速不變。

戰績上方按出戰牌組出現場次顯示常用武將／兵種／法術卡圖，每類一張；試煉取本機全部紀錄，真人取伺服器最近 30 場本人牌組。下方僅顯示最新 5 場細節，不刪除舊紀錄。


## 裝備與出牌操作（2026-10-05）

- 主公可裝備全部四類，武將僅可裝備武器，兵種不能裝備。裝備頁可選主公或本國武將；同一件裝備只能供一名角色使用，多件同款可分配給不同角色。武將武器只增加該武將的攻擊，每次召喚皆套用，不能疊加或加成其他武將／兵種。主公四欄位：武器增加攻擊、鎧甲增加生命、護符增加聚氣效率、坐騎增加移速。每類三件，共 12 件；精良／稀有／史詩加成 2%／4%／6%。主公穿戴加成只作用主公與該方聚氣；武將穿戴武器只加成該武將攻擊，兵種與建築數值不變；重複持有不疊加，復活保留加成。真人配對時鎖定穿戴快照，配對／對戰中不能換裝。已登入者可在試煉使用裝備，但試煉不掉落。
- 只有伺服器正常完成的真人對戰／國戰掉落；至少 20 秒且雙方有走位、出牌或絕招操作。每人每場一件，勝敗／平手都可得；勝方史詩 6%、稀有 24%、精良 70%，其他史詩 2%、稀有 13%、精良 85%；四欄位等機率。投降、斷線、試煉、訪客無掉落。同一對手台灣每日最多 3 場掉落，與國戰貢獻的重複限制分開計算。
- 掉落、戰績、收藏在同一伺服器交易保存，重試不重複領取；舊帳號自動補空收藏，不回填舊戰績。裝備身份、欄位、所有權由伺服器驗證，profile API 不接受自行寫入收藏。
- 手牌可拖曳，亦可點卡再點戰場；再點同卡取消選擇。拖回手牌區取消、不扣費；無效位置不送出操作。新增選牌抬起、部署等待／成功標記、角色腳下陰影及雙方辨識環，卡牌框與費用更清楚。
- 真人操作確認回應直接包含權威戰場狀態及操作版本，立即更新手牌，避免同時間較舊的輪詢覆蓋出牌結果。仍採輪詢；尚未加入 WebSocket、獨立角色逐格／骨架動畫或裝備專用美術。

- 戰場存活角色顯示名稱與血條，我方固定綠色、敵方固定紅色，不受所屬國家影響；真人客方經視角翻轉後仍為我綠敵紅。腳下辨識環與基地玩家名稱同步使用敵我色。
- 牌組選擇區未選卡牌灰階且降低亮度，已選保持彩色與亮框；反灰卡牌仍可點選。
